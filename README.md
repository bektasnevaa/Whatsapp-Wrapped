# WhatsApp Wrapped

WhatsApp Wrapped is a simple web app that analyzes exported WhatsApp chat files and turns them into a summary dashboard.

## Features

- Upload a WhatsApp '.txt' chat file
- Count total messages
- Count total words
- Find the top sender
- Find the most active day
- Find the most active hour
- Find the longest message
- Find the most used word
- Find the most used emoji

## Privacy

The chat file is processed locally in the browser. It is not uploaded to any server.

## Built With

- HTML
- CSS
- JavaScript

## How to Use

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Run the project using Live Server
4. Upload an exported WhatsApp `.txt` chat file.
5. View your WhatsApp Wrapped summary.
